## Security Policy

NexusTek takes the security of our software, workshops, and sample code seriously. While the materials hosted in this repository are designed for learning, demonstration, and workshop exercises, we welcome feedback and disclosures from the security research community and event attendees.

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.**

If you believe you have discovered a security vulnerability in this repository or any NexusTek public project, please disclose it responsibly:

1. **Email Us:** Send a report directly to the NexusTek Security Team at **SOC@nexustek.com**.
2. **Details to Include:**
* The repository name and affected file(s) or branch.
* A detailed description of the vulnerability and its potential impact.
* Step-by-step instructions or a proof-of-concept (PoC) to reproduce the issue.
* Your name/handle if you would like to be acknowledged upon resolution.



---

## What to Expect

* **Acknowledgment:** We aim to acknowledge receipt of your vulnerability report within **2 business days**.
* **Assessment & Fix:** Our engineering and security teams will investigate the finding, determine its impact, and work on a fix or remediation plan.
* **Updates:** We will keep you updated on the progress of the resolution.
* **Public Disclosure:** Once a resolution or patch is released, we can coordinate public disclosure or update the repository content as appropriate.

---

## Safe Harbor & Scope

* **In Scope:** Code, samples, workflows, and configuration scripts contained directly within NexusTek public GitHub repositories.
* **Out of Scope:** Demonstrations using simulated or intentionally weak security patterns designed solely for instructional workshop purposes (these are typically marked with inline warnings).
* **Guidelines:** Please do not attempt to access or modify data belonging to other users, perform denial-of-service (DoS) tests against workshop infrastructure, or target NexusTek corporate systems during your research.

Thank you for helping us keep NexusTek resources safe for the community!
