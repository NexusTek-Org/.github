# NexusTek Open Source & Workshop Repositories

Welcome to the official public GitHub organization for **NexusTek**.

While the majority of NexusTek’s core software engineering, proprietary systems, and internal tools live in our private enterprise repositories, we periodically publish select resources here for community learning, technical workshops, open-source projects, and developer samples.

---

## 🚀 Public Resources & Sample Repositories

The repositories hosted in this public organization are curated specifically for external developers, workshop attendees, and technology partners:

* **Workshop & Event Labs:** Hands-on tutorials, slide decks, and code samples accompanying our technical sessions, AI workshops, and community events.
* **Reference Implementations:** Production-ready architecture blueprints, boilerplate setups, and standard patterns for integrating with NexusTek integrations and tools.
* **Public Utility Tooling:** Select open-source libraries, CLI utilities, and helper packages maintained by our engineering teams.

---

## 🔒 Security & Vulnerability Reporting

At NexusTek, security is integral to everything we build. All software and code samples published in this organization undergo internal security vetting prior to public release.

If you discover a potential security vulnerability in any of our public repositories or projects:

1. **Do not create a public GitHub Issue or Discussion.**
2. Report the finding directly to our security team via email at **SOC@nexustek.com** (or reference the specific [`SECURITY.md`](https://github.com/NexusTek-Org/.github/blob/main/SECURITY.md) file located within individual repositories).
3. Include details on the affected repository, steps to reproduce, and any relevant proof-of-concept details so we can investigate promptly.
