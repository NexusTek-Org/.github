# Welcome to NexusTek on GitHub 👋

NexusTek uses this GitHub organization to selectively and periodically publish technical workshops, hands-on labs, open-source projects, and code samples for our workshop attendees, clientele, developers, and technology partners.

---

### 📌 About Our Public Repositories

While the vast majority of NexusTek's software engineering, client solutions, and internal tooling remain inside our private enterprise repositories, you can find the following here:

* **🛠️ Workshop & Event Labs:** Step-by-step hands-on guides, sample code, and exercises for our Microsoft AI and cloud engineering events.
* **📐 Reference Implementations:** Architectural patterns, integration samples, and starter boilerplates.
* **🔧 Open-Source Utilities:** Select open-source scripts, CLI tools, and community libraries maintained by NexusTek engineering.

---

### 🔒 Security & Responsible Disclosure

Security is fundamental to everything we build at NexusTek.

* If you discover a potential vulnerability in any of our public repositories, **do not open a public issue or pull request**.
* Please report findings directly to our Security Operations Center at **[SOC@nexustek.com](mailto:SOC@nexustek.com)**.
* See our organization-wide [`SECURITY.md`](https://github.com/NexusTek-Org/.github/blob/main/SECURITY.md) guidelines for full details.
